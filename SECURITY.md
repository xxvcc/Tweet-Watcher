# Security Policy

## Maintenance status

Tweet Watcher v1 reached end of maintenance on **2026-10-29**. **All v1 versions, including the final release 3.5.0, are unsupported and will not receive security updates.** The repository remains available and is not archived; this does not imply active support.

Development continues in [Tweet-Watcher-v2](https://github.com/xxvcc/Tweet-Watcher-v2). Review its [security policy](https://github.com/xxvcc/Tweet-Watcher-v2/blob/main/SECURITY.md), [verification limits](https://github.com/xxvcc/Tweet-Watcher-v2/blob/main/docs/VERIFICATION.md), and [migration guide](https://github.com/xxvcc/Tweet-Watcher-v2/blob/main/docs/MIGRATION.md) before switching. v2 is currently a prerelease.

## Reporting a vulnerability

Do not publish credentials, tokens, cookies, unredacted logs, or exploit details in a public issue.

If an issue also affects v2, report it through the private channel described in the v2 security policy. For a v1-only finding, use this repository's **Security → Advisories → Report a vulnerability** channel if available; there is no commitment to a fix or response time. If private reporting is unavailable, do not post technical details publicly.
